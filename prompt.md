# NuExis Website — Google Flow (Omni) Video Prompts

## Overview

This file contains **9 video prompts** for Google Flow using the **Google Omni model**.
Each prompt generates approximately **10 seconds** of video, totalling **~1 minute 30 seconds** — one complete, polished explainer video about the NuExis website.

**Model:** Google Omni
**Duration per clip:** ~10 seconds
**Total clips:** 9
**Total video length:** ~1 minute 30 seconds
**Video Style:** Dark mode cinematic — deep navy/black backgrounds with blue & indigo accents. The NuExis website itself is light mode, so website screenshots will appear as bright UI panels or laptop mockups overlaid on the dark cinematic background, which creates a striking contrast and premium feel.

> **💡 Dark vs Light Mode Decision:**
> Use **dark mode** for the overall video aesthetic. It looks far more cinematic and premium for a product explainer. The actual NuExis website is light mode (white backgrounds), so when you show website screenshots, they appear as glowing UI overlays inside a laptop or monitor mockup on a dark background — giving the best of both worlds.

---

## How to Use in Google Flow

1. Open **Google Flow** and start a new project.
2. Set the model to **Google Omni**.
3. For each prompt below:
   - Create a new clip/scene
   - Paste the **full prompt text** (including the image reference lines) into the generation field
   - Upload/attach the images listed under **"Attach these images"** directly into the clip
   - Generate the 10-second clip
4. Arrange all 9 clips in sequence in the timeline.
5. Add smooth **crossfade transitions** (0.5–0.8 seconds) between clips for seamless flow.
6. Add background music (ambient/corporate — e.g., calm electronic or orchestral).
7. Export at 1080p or 4K.

## About NuExis (Background for Context)

NuExis is a professional **Audio-Visual (AV) solutions company** based in **New Delhi, India**. Their website serves as a comprehensive **B2B product catalog and support portal** for AV technology. Key features of the website:

- **Product Catalog** — 9+ product series, 50+ products across Digital Signage, Touch Displays, Podiums, Conference Systems, Pro Audio, Conferencing, Active LED, Switching & Controls, and Accessories
- **Dynamic Routing** — Each product has a dedicated URL and detail page with specs and image galleries
- **Gallery Page** — Filterable grid of real installation photos with lightbox viewer
- **Support Center** — Technical support, sales inquiries, contact form, and interactive map
- **Admin Panel** — Protected admin dashboard to manage products, gallery, carousels, and user requests
- **Authentication** — Supabase-powered login/signup with OTP verification and Google OAuth
- **WhatsApp Button** — Direct quick-contact floating button
- **FAQ Section** — Categorized with search and accordion UI
- **Testimonials** — Client reviews and ratings
- **Client Logos Carousel** — Infinite scroll of partner/client logos

*Built with React 19, TypeScript, Vite, Framer Motion, and Supabase.*
